# 검증 기록

2026-09-23 기준으로 `pnpm typecheck`와 Vinext 빌드가 성공했습니다. 빌드 후 `pnpm start`에서 홈은 HTTP 200, 잘못된 데이터 API 요청은 HTTP 400으로 응답했습니다.

게시된 사이트에서 KBO·NPB의 당일 일정과 순위, CPBL의 2026년 순위가 실제 제공처 데이터로 표시되는 것을 확인했습니다. NPB 게임차는 스포나비의 직전 순위 기준 수치를 선두 기준으로 다시 계산해 확인했습니다.

데스크톱과 320px 모바일 미리보기에서 팀 선택의 대륙·리그 탭, 가나다순 목록, 경기 카드의 팀 이름 줄바꿈, 기록 탭의 회색 선택 상태와 가로 넘침 여부를 확인했습니다. 이번 `우리 집 경기` 문구 변경은 타입 검사와 빌드로 확인했습니다.

실제 iOS·Android 기기에서의 시험이나 경기 제공처의 장기 가용성 검증을 뜻하지는 않습니다. 계정과 기록은 브라우저 로컬 저장 방식이며 서버 인증이나 기기 간 동기화는 없습니다.
