# 실제 야구 데이터 연결

2026-09-23 기준. 날짜와 경기 시작 시간은 한국 시간으로 표시합니다.

| 리그 | 일정·점수 | 순위 | 제공처 |
|---|---|---|---|
| KBO | 연결 | 연결 | 네이버 스포츠. 서버 경로 `app/api/baseball/route.ts`에서 조회 |
| NPB | 연결 | 연결 | Yahoo! JAPAN 스포나비. 서버 경로에서 조회 |
| CPBL | 미연결 | 연결 | CPBL 공식 팀별 기록의 같은 연도 상·하반기 승·패·무 합산 |
| MLB, LMB, LIDOM, LBPRC, LVBP, ABL | 연결 | 연결 | MLB Stats API |
| 그 밖의 리그 | 미연결 | 미연결 | 제공처 연결 준비 중 |

홈은 열려 있을 때 약 60초마다 일정과 점수를 다시 확인합니다. 일부 제공처가 실패하면 가능한 리그의 결과를 표시하고 실패 리그를 안내합니다. 모두 실패하면 재시도 화면을 표시하며 예시 데이터로 대체하지 않습니다.

KBO·NPB·CPBL은 서버 경로 `/api/baseball`을 사용하므로 정적 파일만 배포하는 GitHub Pages에서는 작동하지 않습니다. NPB 스포나비 순위는 현재 시즌만 제공합니다. 순위의 게임차는 선두 팀 기준으로 계산합니다. CPBL은 순위만 연결돼 있으므로 홈의 CPBL 경기 일정은 아직 표시되지 않습니다.

MLB Stats API의 UTC 경기 시간을 한국 시간으로 변환하고 선택 날짜의 경기만 표시합니다. 취소·연기·진행 상태와 시작 시간 미정은 별도로 표시합니다. 제공처의 갱신 지연, 접속 제한, 데이터 형식 변경이 생길 수 있습니다.
